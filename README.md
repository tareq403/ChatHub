# ChatHub

A desktop application that aggregates multiple AI chatbots into a single interface.

## Supported Tools
- Gemini
- ChatGPT
- Claude
- Grok
- DeepSeek

## Features
- **Centralized Interface:** All your AI tools in one sidebar.
- **Session Persistence:** Log in once and stay logged in. Each tool has its own isolated session.
- **External Link Handling:** Any non-AI tool link (e.g., external articles, references) opens automatically in your default system browser.
- **Security:** Built with Electron's latest security practices, including context isolation and navigation restrictions.

## Development
To start the app in development mode:
```bash
npm install
npm start
```
